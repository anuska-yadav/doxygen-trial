# Doxygen Documentation Project

## Overview
This project demonstrates automatic documentation generation using Doxygen for C++ and Python source files.

## Project Structure

```text
trial/
├── first.cpp
├── one.py
├── Doxyfile
├── docs/
├── html/       (Generated HTML documentation)
├── latex/      (Generated LaTeX documentation)
├── README.md
└── .gitignore
```

## Tools Used
- C++
- Python
- Doxygen
- Graphviz

## Generate Documentation

Run the following command:

```bash
doxygen Doxyfile
```

Doxygen generates HTML and LaTeX documentation according to the configuration in Doxyfile.

## Output
- HTML documentation: `html/`
- LaTeX documentation: `latex/`
